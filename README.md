# AlonzoRui

Alon's kid game hub — colorful mini-games for a little flyer and Dad.

Live: https://alonzorui.vercel.app

## Sky Buddies

Couch co-op 3D flying race at `games/sky-buddies.html`.

- **You:** WASD
- **Dad:** arrow keys
- First flyer through 8 glowing rings wins
- Soft bounces, no fail-out, midpoint camera
